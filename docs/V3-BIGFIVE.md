# 观己 V3 · 大五与完整定位服务

版本：3.0-ipip，2026-09-05。沿用V2面向学生、跨专业的个人定位边界；不加入岗位数据库、不承诺适合唯一职业。九型仍不进入此版核心流程。

## 产品与流程

- 免费：独立IPIP-50大五，50题、五项维度、基础解释、免费JSON导出。约7分钟是单独大五模块的体验目标，尚待学生试测，不是全套时长承诺。
- ¥199完整服务：IPIP-NEO-120及30项细分特质 + 兴趣18题 + 价值观8选3排序 + 四类行为经历 + 整合报告 + 浏览器打印另存PDF + 人工沟通。具体沟通安排购买前双方确认，不虚构次数或时长。
- 人工确认微信/支付宝到账 → 发签名兑换码 → 用户兑换 → 完成全套 → 保存PDF → 联系预约沟通。没有自动收款或自动发送报告。
- 50题和120题是不同工具，免费答案不自动拼入付费版。每页10题，可明确跳过、不适用；未处理的问题不能直接翻页。

## 题库与评分

50题来源KatherineGuoGuo/bigfive-open，120题来源rubynor/bigfive-web；保留英文、来源ID、方向、域与细分映射。确切提交与MIT许可见 `public/licenses/bigfive-sources.txt`。中文对照英文适配，不宣传为已验证中文常模。

反向计分为6-x，有效回答均值线性转换为0–100，不是百分位。大五每维至少80%有效回答（50题8/10、120题20/24）；细分特质至少3/4有效。未达阈值显示信息不足，null不当作零。N高分表示情绪敏感，不能误标情绪稳定或诊断焦虑。

兴趣沿用原创探索题，每维3题、至少2有效。价值观只是当前排序；行为经历仅自述，没有外部核验。报告35/65等阈值仍是启发式，不是临床或统计分界。覆盖提示按当次题库长度计算，删除旧三题版的反向差异规则；不输出“真实性分”。

## 数据与访问

默认答案存在页面内存，主动选择后本机保存。免费与完整版本存储键隔离；完整版本升级至career-positioning-v3。V2不转换、不静默删除。生成完整报告会向本站服务端提交答案进行访问校验与计算，不写应用数据库，不调用AI或第三方分析。报告分享由用户自行进行；访问Cookie为HttpOnly。

付费题库和完整报告接口服务端验证签名会话。未配置密钥时关闭兑换。码在设置的到期时间内可复用，不保证单次核销；订单ID可通过撤销列表失效。会话最多24小时且不超过码有效期。运营细节见PAID-OPERATIONS.md。

## 架构与验收

Next.js服务端部署（Vercel），不可使用旧静态out部署。免费题库不引入120题模块；付费题库经受保护接口加载。用户自己的已加载答案与报告不是DRM内容，不承诺离线不可复制。

验收覆盖题库数量和键值、正反向计分、缺失和非法回答、30项细分、过期/篡改/撤销码、接口越权与来源检查、免费完整答题、付费兑换至报告、打印样式和移动端。上线前仍需中文可理解性试测、真实运营联系方式、生产密钥与人工订单台账。
