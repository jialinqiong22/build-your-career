# 观己 V4 · 四维基础与可选动机补充

2026-09-06，规则版本4.0-layered。V4 已进入功能分支与 Vercel Preview 验收阶段；Preview 使用独立 Neon 分支，不直接写入 production 数据库。

## 模块与权益

1. 职业价值观：原创40题，八维各5题，6–10分钟；完成后主动排序三项诉求。明确非施恩职业锚、非舒伯WVI、非标准化量表。
2. 霍兰德职业兴趣：当前保留原创18题RIASEC探索版，3–5分钟。尚未核得适合本产品直接商用的经典90题，不能标称90题已接入；已询问是否接受原创90题，未确认前不擅自替换。
3. 大五：IPIP-50免费，约7分钟；完整套餐采用IPIP-NEO-120，15–22分钟、五维加30项细分。两个工具独立作答，非追加70题。
4. 潜力证据与成长条件：五类经历，8–15分钟，也可每类明确暂不提供。记录情境、本人行动、结果、过程、反馈、支持条件、下次需要。
5. 九型人格：用户已同意原创36题动机反思，5–9分钟，九类各4题，非经典RHETI或标准化量表。属于199元套餐可选项，整项跳过不会改变四维报告。

基础完整流程约35–55分钟（非承诺，待试测），九型另计；可模块切换和本机续答。199元仍为完整流程+浏览器另存PDF+人工沟通，微信/支付宝人工确认收款后发码。正式密钥和联系渠道未配置前不收款。免费入口不需要GitHub或任何账号。

## 计分与分档

各工具单独显示有效题均值的线性0–100，不是百分位、能力或成功率，不合成个人总分。价值观每维至少4/5有效，兴趣每维3/3有效、九型每类4/4有效；大五80%域覆盖及3/4细分覆盖。null代表主动跳过，不当作低分。分数接近时并列说明，不强行选唯一职业或人格。

证据分档只依据填写结构：情境、行动、结果、过程四字段有信息且至少三个不同内容视作较完整；完全相同记录去重，少数明显空白占位词不算信息。没有完整记录为limited；一条或多条没有反馈/结果线索为some；至少两条不同完整记录且一条有结果线索为rich。文字长短不增加分数，学历和方向清晰度不参与分档。不能识别真实性或所有语义质量，重复改写也无法可靠识别，需明确该局限。

报告limited侧重探索任务、some强调在另一场景验证、rich强调迁移与支持条件边界。始终注明自述未经核验，信息丰富不等于能力强。用户填写的支持与需求原文单列；大五产生的环境建议标为待验证条件。方向清晰度只改变引导，不以年级推断经历丰富度。

九型答案完全独立于核心answers，core report函数不读取它；跳过时删除九型答案，导出也不保留。报告单独给动机反思，不输出隐藏恐惧诊断或翼型确定结论。

## 数据、接口与预览

V4 Profile存储键career-positioning-v4，不自动转换或删除V2/V3；免费大五另有存储键。明确选择本机保存才写localStorage，取消保存会删除V4记录。记录损坏拒绝载入。过期后仍可从/assessment删除本机V4数据。正文暂存于页面，生成正式报告时发同站API，不写应用数据库、不发第三方。分享需用户自行操作。

服务端题库返回bigFive与enneagram。报告API验证同源、付费签名会话、schema和完成度，100KB请求体上限。客户端生成请求带取消机制，修改/导航/清除使旧响应失效，避免过期结果覆盖。打印前重新确认访问；失效时保留当前回答，并提示新标签重新兑换。

开发环境/preview将题库直接传给同一客户端流程，报告在浏览器计算，标明仅验收。生产环境必须404，不使用localStorage伪造付费权限。开发服务器绑定127.0.0.1。本机预览不算支付订单、不发真实兑换码。
