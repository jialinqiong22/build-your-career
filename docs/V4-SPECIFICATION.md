# 观己 V4 · 四个必做模块与结果留存

2026-10-07修订，品牌为 Anchor Point Career。规则版本仍为4.0-layered，以兼容现有回答；本次产品要求取代此前的经历模块及可选九型方案。本次发布候选包含以下规则，实际部署状态以发布记录为准。

## 用户流程

完整流程为：打开测评 → 完成四个模块 → 生成报告 → 一键生成并下载统一结果长图，也可分别保存四张模块图 → 添加微信 → 自行发送愿意分享的结果及求职定位问题 → 人工确认沟通时间及服务安排。

1. 大五人格：免费入口保留IPIP-50；完整套餐按现有权益提供50题或120题。两版分别作答，不将50题当成120题的前段。
2. 霍兰德职业兴趣：原创18题RIASEC探索版，不标称经典90题标准版。
3. 职业价值观：原创40题，八维各5题，另主动排序三项诉求，不标称施恩或舒伯原版。
4. 九型人格：原创36题动机探索，九类各4题。必做，移除整模块跳过入口。

删除经历填写、潜力证据及成长条件收集，报告不再按经历信息分档。保留题目级“无法判断”；不把未知当作低分。模块完成表示每题作答或明确无法判断，信息不足的维度仍不会给出分数。四模块未完成时不生成完整报告。

## 结果与图片

四模块独立计分，不合成人格、能力或岗位匹配总分。结果图统一版式、日期、品牌及说明：

- 大五：五个维度0–100描述分，展示情绪稳定性（100减情绪敏感性）。不是人群百分位。
- 霍兰德：六类分数；信息完整、前三位及第三/第四没有并列、最高分至少50时显示三字母兴趣代码，例如RIA。并列或缺失时说明未分化。
- 价值观：八维分数及用户主动选择的三项取舍顺序。
- 九型：九类分数；完整且唯一最高分至少50时给出探索性主型，相邻两型较高的一型作为翼型，例如7w6。主型并列则未分化；翼型并列单独说明。这个规则没有心理测量验证。

结果图片由浏览器Canvas生成，不经图片接口上传回答或分数。完整报告生成一张统一长图及四张模块图；按钮自动发起统一长图下载，并保留预览及每张保存链接。单模块完成后也能生成该模块图片。微信或移动系统可能限制下载；预览图可供长按或截图留存。成功以设备相册/文件能找到可读图片为准，不能只看按钮已点击。

添加微信和预约仍为人工流程，不自动发送结果，不自动预约，不承诺测评给出唯一职业。

## 数据、权限与旧记录

免费大五无需注册。当前完整套餐沿用服务器签名兑换权益，未改变收费、收款或登录规则；是否四模块全部免费正在向用户确认。正式密钥或联系渠道未配置时，继续按现有方式关闭兑换/收款。

默认页面暂存，明确选择本机保存才写localStorage，取消保存删除本机对应记录。云端保存需用户主动操作；恢复旧V4时移除历史经历字段并要求完成九型，不删除原有历史记录。免费50题和不同完整题库存储键独立。报告通过同源API验证权益与完成度，不因本机标记获得收费权益；修改或导航使旧异步请求失效。

开发验收入口/preview只在development开放，生产返回404，开发服务器绑定127.0.0.1。验收使用模拟回答，无订单，不写真实客户结果。

## 当前边界与验收

题库来源与许可保留在public/licenses；本地代码检查不等于量表验证。国内普通手机网络与微信内置浏览器无VPN可达仍未解决，需要单独验证托管、域名和资源。不能把390px桌面模拟当成手机实测。

验收覆盖四模块完成度、旧数据兼容、移除经历、兴趣代码及翼型的并列/缺失边界、情绪稳定性变换、结果图片生成、本机续答、手机宽度排版、现有鉴权及生产构建。微信保存到相册仍待实机验证。
