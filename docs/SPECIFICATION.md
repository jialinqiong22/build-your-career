# 观己 · 个人定位仪 V2

版本：2.0-exploration，2026-09-05。此文档取代旧版产品定义。

## 产品承诺与范围

面向本科、硕士在读及应届生，跨专业、跨行业。回答什么吸引我、如何做事、重视什么、有什么行为证据。输出可修订的个人画像、任务与环境偏好、取舍和验证行动。不输出岗位榜单、薪资、成功概率、人格命运判断。九型暂不进入 MVP，未来仅作用户主动选择的反思补充。

## 流程

首页 → 使用说明与本机保存选择 → 阶段与方向清晰度 → 兴趣18题 → 工作方式15题 → 价值观8项排序取舍 → 4项行为经历 → 报告。可后退修改，明确提供不了解/没有经历；可选本机续答，默认仅内存。打印/另存PDF、导出个人数据、删除本机记录。无账号、付款、追踪、第三方数据传输。

## 测量边界

本版使用依据 RIASEC、大五概念设计的原创中文探索题，不是标准化量表，不继承其他量表信效度，不作人群百分位解释。预计用时需实际试测，界面不承诺精确时长。未来使用成熟题库必须核验许可、中文版本及适用人群，并重新版本化。参考： https://ipip.ori.org/ 、 https://www.onetcenter.org/tools.html 。

## 模型和评分

兴趣6维，每维3题，喜欢程度1–5；未知为null，不能当低分。工作方式5维，每维3题，符合程度1–5，含反向计分6-x。分数为有效题均值线性映射0–100，仅用于本次回答描述。至少2题有效才展示该维度；差距不超过8分视为接近，不强行选唯一类型。

价值观：从成长、收入、稳定、自主、贡献、平衡、协作、认可中依次选3项，可取消重排。仅表示当前相对优先级，没有总体价值高低分。

行为证据：分析、创造、协作、执行四类，分别填写行为、本人行动与结果。经历状态为无经历、尝试、完成作品、获得反馈；选择有经历须填写至少12字说明。所有内容均为自述，反馈未被外部核验；不能由文字长度或标题推断能力。没有经历只表示缺少信息。

不合成总匹配分，不把回答一致性当真实性。数据提示仅报告有效覆盖、单一选项、反向题差异及证据缺口。规则版本与题库版本随导出保存。

## 报告规则

一句话定位来自有效兴趣首组、工作方式与价值观，数据不足时显式保留空白；完整显示6项兴趣与5项工作方式，不称能力雷达。贡献方式以兴趣候选活动呈现，并匹配自述经历的支持情况。环境建议由工作方式两极触发，价值冲突提示同时保留双方偏好。方向清晰度仅改变引导文案，不改得分。报告包含原始行为说明、已有线索/待验证假设、一个可执行的7天探索任务。结果避免职业、行业刻板印象。

## 架构

### 探索规则参数

- 兴趣首组仅在最高分至少50、且距最高分8分内的维度不超过3个时用于摘要；否则提示尚未明显分化。此阈值是产品启发式，不是经验证的心理学分界。
- 工作方式以35/65作为描述区间，中间区间给出混合环境建议。情绪敏感的高分仅提示反馈与恢复空间，不推断抗压能力或心理诊断。
- 有效回答少于26题提示覆盖不足；至少15个有效回答且全部同一选项时提示复核；同一工作方式维度的首题与反向末题转换后相差至少3档时提示情境差异。都不用于判断用户诚实程度或输出“可信度百分比”。
- 六类活动原型：动手实践、研究分析、创意表达、帮助支持、影响推动、条理组织。每类配一项七天任务。经历分类对应仅提示“相关类别有自述”，不能认定具体活动能力已被证明。
- 摘要主要归纳兴趣和价值观；工作方式、行为记录单独呈现，避免强行推断一个综合人格类型。未来评估题库和规则时同步调整版本号。

Next.js App Router + TypeScript + 静态导出，Cloudflare Pages继续使用next build与out目录。lib/assessment.ts保存题库、类型、纯评分函数与可解释规则；app/page.tsx负责交互；不调用大模型。仅显式选择保存后使用localStorage，带schema验证；存储不可用提示且保持内存答题。导出包含自述，分享由用户自行决定。

## 验收

能从空白完成所有步骤、跳过未知题、后退保持答案、修改并更新报告；未答不能前进，null算已明确跳过；反向题正确；无效/损坏/旧版本存储不载入；关闭保存清除缓存；清除全部后不再有可恢复数据；打印隐藏导航和操作；移动端无横向溢出，键盘焦点可见、选项语义明确；生产构建、TypeScript、评分和恢复边界测试通过。上线前进行目标学生可理解性试测；此轮不自动推送或部署。
