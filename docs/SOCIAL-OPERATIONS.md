# 邀请对比与经历反馈

默认关闭。启用前先完成账号数据库配置与迁移，再在同一专用数据库执行 scripts/social-migration.sql，设置 SOCIAL_ENABLED=true 并重新部署。缺配置时API返回503，按钮明确显示尚未开放。

对比邀请7天有效；反馈邀请及回答自创建起最多30天。生产需安排每日执行 `node scripts/cleanup-social.mjs`，物理清理所有到期记录。到期判断直接作用于每个API请求，不依赖清理任务。上线前运营方应确认隐私告知、保留期、响应删除请求的联系方式和数据库访问权限。

创建邀请必须由用户主动确认。数据库只存邀请token、独立发起人secret、独立参与人secret和反馈删除凭据的SHA-256哈希；每个原始token均为32随机字节。公开邀请链接不包含账号ID或分数。发起人浏览器保存管理凭据，受邀人完成同意后获得另一个浏览器凭据。不要把邀请URL或凭据写入分析、第三方聊天或日志。

对比状态：pending_assessment → pending_initiator_consent → active。受邀人读完告知、完成测评、勾选同意后才能提交其分数；发起人必须再最终确认。双方确认之前，任何角色的API都不会收到另一方分数；未持有参与凭据的公开链接访问者即使active也无法看到分数。双方可撤回。事务行锁防止两个访问者并发占用同一邀请。参与分数来自本地自我报告，服务不把它视为考试或认证。

匿名发起人可通过邀请管理页主动绑定真实账号，绑定仅允许原管理凭据持有者且不可转绑。之后需原账号登录和浏览器凭据同时成立。清空浏览器会丢失匿名管理凭据，分享前请注意这一点。当前没有跨设备恢复管理凭据功能。

反馈仅复制一条具体经历摘要和固定三问。生成前用户预览实际摘要；受邀人无需账号，不收集联系方式。回答提交前可预览并勾选同意，提交后保存独立删除凭据。凭据可删除回答，即使发起人已撤回或邀请已到期；记录已清理则不存在可删除数据。反馈与自述分开显示，明确未经核验。发起人可查看和撤回，受邀人无法读取已存回答或其他经历。

调用方组件：`SocialCompare({scores:{O,C,E,A,N}})`、`EvidenceFeedback({evidenceItemId,summary})`。N沿用大五原始情绪敏感性量尺，不在对比时反向转换。访问接口 `/api/social/invites` 及 `/api/social/invites/[token]`；所有写请求强制同源并有数据库频率限制，正文最多12000字节。响应private/no-store，无搜索索引，Referrer-Policy为no-referrer。

测试覆盖双方同意之前/之后、撤回、过期、访客信息边界与输入校验。完整上线仍需在配置后的隔离数据库进行双浏览器邀请、并发占用、账号绑定、撤回与删除端到端验收；无配置的生产部署不能宣称这些流程已实测。
