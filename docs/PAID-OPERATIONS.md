# 199 元完整探索套餐：人工收款与兑换

套餐包含 120 题大五、兴趣、价值观、行为证据、完整 PDF 与人工沟通。免费版为 50 题大五。人工沟通的时长、预约方式和联系入口尚待运营方确定，不默认承诺具体时长或即时服务。

## 上线配置

这是需要 Node.js 服务端的 Next.js 应用，不能使用静态导出部署。Vercel 项目需配置 `PREMIUM_ACCESS_SECRET`，使用密码学随机生成的至少 32 字节密钥，不得放进 `NEXT_PUBLIC_`、代码仓库、网页或浏览器。发码设备环境使用同一个密钥。没有密钥时付费服务关闭，没有内置通用兑换码。

微信/支付宝收款二维码及客服联系入口尚未提供；上线前由运营方补齐真实入口。不要把密钥或兑换码放进分析平台、公开截图或日志。

## 每单流程

1. 用户通过运营方提供的微信或支付宝渠道支付 199 元。
2. 运营方核实实际到账；截图本身不作为到账依据。
3. 在自己的订单记录中建立不含姓名、邮箱或手机号的唯一订单编号，记录付款与服务履约情况。选择并告知用户兑换有效期。
4. 在配置好密钥的本地终端运行以下命令。要求 Node.js 22.6+（支持 TypeScript 类型擦除），时间必须含明确时区；示例编号及日期需要替换。

```sh
node --experimental-strip-types scripts/issue-access-code.mjs --order ORDER_2026_0001 --expires 2027-01-01T00:00:00+08:00
```

5. 将生成的兑换码私下交付该用户。用户在应用兑换，服务端签发最多 24 小时会话，且不会超出兑换码有效期。到期后用户可以在原兑换码有效期内再次兑换。
6. 用户完成全部测评后导出 PDF，按运营方约定渠道预约人工沟通。发码并不代表沟通已履约。

## 权限与限制

兑换码是可复用的持有者凭据，不是一次性码，也没有账户绑定、设备绑定、次数限制或订单数据库。持有者可以复制转发；运营方应了解这一限制。浏览器通过 HttpOnly / SameSite=Strict Cookie 保存会话，生产环境启用 Secure。服务端验证签名、用途、产品、期限与撤销名单；浏览器的本地标志不构成授权。已经下载的题目、报告或 PDF 无法远程撤回。

撤销单笔权限：把订单编号加入服务端 `PREMIUM_REVOKED_ORDERS`（逗号分隔），然后重新部署或重启。已有会话在下次受保护请求时也会被拒绝。重新发码前本地发码环境也应同步撤销名单。轮换 `PREMIUM_ACCESS_SECRET` 会使所有旧码及会话失效，应安排重新交付。

## API 合约

V4新增：`GET /api/premium/bank`返回`{bigFive,enneagram}`；`POST /api/premium/report`接受V4 Profile并返回`{report}`，请求体最多100KB；两者未授权返回403。`/assessment`为完整用户流程；`/preview`仅开发环境本机验收，生产返回404。九型可跳过，不影响基础报告；本次套餐仍为199元，不另加九型费用。

- `GET /api/premium/access` → `{ configured, active, expiresAt }`，时间为 ISO 字符串或 null，禁止缓存。
- `POST /api/premium/access`，同源 JSON `{ code }` → 同上，设置会话 Cookie；请求体最多 2048 字节。无效码 401，异源 403，未配置 503。
- `DELETE /api/premium/access`，同源请求，清除当前 Cookie。不会撤销兑换码本身。
- 其他付费接口必须调用 `premiumAccessFromRequest(request)`（来自 `lib/premium-access.ts`），空值返回 403，且响应设置 `Cache-Control: no-store, private`。120 题库与付费报告不能通过免费页面静态导入泄漏。

没有接入支付 API，网页不自动验证微信/支付宝到账。服务端不收集支付账户或学生身份信息；运营方自行保管的收款记录与沟通资料不属于本应用自动存储。
