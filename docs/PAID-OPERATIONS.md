# 9.9元与99元服务：人工收款和账号绑定兑换

免费提供50题大五。9.9元提供完整四维与在线规则小结；99元增加独立120题大五、PDF与一次1对1沟通。沟通时长、安排、取消退款规则需在购买前确认。

## 配置

配置有效账号服务、至少32字节随机 `PREMIUM_ACCESS_SECRET` 以及真实 `PREMIUM_CONTACT`。密钥仅在服务端与受信任发码设备存在。未配置时不收款，不展示可用的支付能力。

## 每单流程

1. 用户登录，服务方确认对应账号ID和所购套餐。
2. 服务方通过实际到账确认付款，建立非个人信息订单编号。
3. 配置相同服务端密钥的发码终端执行：

```sh
node --experimental-strip-types scripts/issue-access-code.mjs --order ORDER_2026_0001 --expires 2027-01-01T00:00:00+08:00 --user 42 --plan standard
```

99元使用 `--plan guided`。ID、订单号与到期时间必须替换为实际值。兑换码私下交付该用户。

4. 同一账号兑换后签发最长24小时HttpOnly/Secure/SameSite=Strict套餐会话。有效期内可在同一账号的其他设备重新兑换。无单独订单数据库，运营保留履约记录。
5. 99元用户完成测评后，通过浏览器另存PDF并按事前约定预约沟通。

## 权限与兼容

所有题库、报告、PDF接口均同时验证账号会话和签名套餐凭据；篡改客户端状态不能获得权益。复制兑换码或套餐Cookie到不同账号会被拒绝。撤销订单使用 `PREMIUM_REVOKED_ORDERS`，重启/部署后生效。

旧199元签名码仍可校验，但必须先用 `PREMIUM_LEGACY_ORDER_OWNERS` JSON将旧订单明确分配到用户ID，例如 `{"OLD_ORDER":42}`，再兑换为绑定会话。未分配的旧码不能由任何账号抢先认领。

`GET /api/premium/access` 返回 `{configured,active,plan,canPrint,expiresAt}`；`GET /api/premium/bank` 按权益返回50或120题及可选九型；`POST /api/premium/report` 校验对应题库和完成度；`?format=pdf` 仅允许guided。浏览器原生打印、截图或已下载内容无法远程禁止。

无支付API、自动订阅和自动扣费。本次生产环境仍缺少账号及套餐配置，真实付费联调尚待配置完成。

## 注销与已购权益

用户可在 `/my-assessments` 自助注销账号（密码二次确认，立即生效），会话、云端测评记录与社交邀请随之级联删除。已兑换的套餐凭据绑定账号ID，账号删除后自动失效；兑换码本身无法在新账号重复使用。用户注销前咨询退款或数据导出时，仍通过 Crisp 人工处理；注销后如需恢复，只能重新注册，历史履约记录按运营保留策略处理。
